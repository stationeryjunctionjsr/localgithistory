# Stationery Junction - Next.js Frontend (New Tech Stack)

This is the Next.js/TypeScript frontend for the new tech stack version.

## Setup

```bash
npm install
```

## Run

```bash
npm run dev
```

Runs on http://localhost:3001

## Environment Variables

Create `.env.local` file:

```env
NEXT_PUBLIC_API_URL=http://localhost:8000/api
PORT=3001
```

## Build

```bash
npm run build
npm start
```

## Backend

The backend for this frontend is in the `../backend` folder.
